# Premium Graphite Calculator

A desktop calculator built with **Python** and **CustomTkinter**, featuring a modern dark interface with subtle teal accents.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Clear and backspace buttons
- Percentage and sign-change operations
- Keyboard support
- Error handling for invalid calculations
- Premium Graphite dark theme

## Requirements

- Python 3
- CustomTkinter

## Installation

Install the required library:

```bash
pip install customtkinter
```

## How to Run

Run the following command in your terminal:

```bash
python gui_calculator.py
```
